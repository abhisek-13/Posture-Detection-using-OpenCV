# Posture Detection Web App

## Overview
The Posture Detection Web App is a basic-level project that uses OpenCV to detect and analyze your posture. The app accesses the device's camera and shows you information about your posture, such as how you are standing and what you are doing. This project includes a simple user interface to provide real-time posture detection.

## Features
- **Real-Time Posture Detection:** Uses OpenCV to access the device's camera and analyze the user's posture.
- **User Interface:** A simple interface to display posture information in real time.

## Technologies Used
- **Python:** Programming language used for the development of the project.
- **OpenCV:** Library used for computer vision tasks, including accessing and processing camera input.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/posture-detection-web-app.git
    cd posture-detection-web-app
    ```
2. Create and activate a virtual environment:
    ```bash
    python -m venv venv
    venv\Scripts\activate  # On Windows
    ```
3. Install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

## Usage
1. Run the Python application:
    ```bash
    python app.py
    ```
2. Allow the application to access your device's camera.
3. View the real-time posture detection on the interface.

## Project Structure
- `app.py`: Main application file for running the posture detection web app.
